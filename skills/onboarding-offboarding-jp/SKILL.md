# 入退社手続きの段取り

## 概要

従業員が入社・退社するたびに、人事・総務・情シス・本人・上長にまたがる十数個の手続きが同時に走る。専任の人事がいない会社では、誰かが思い出した順にやるので「保険の届出が期限を過ぎた」「退職者のアカウントが3か月生きていた」「前職の書類をもらい忘れて年末に慌てた」が起きる。このスキルは、その手続きを**時系列のチェックリスト(担当・期限つき)**と**台帳に残す記録項目**の形に組み立てるためのものである。判断と提出は人間の担当者・専門家(社労士・税理士)の仕事であり、このスキルは**その手前まで**を引き受ける。

## 前提と範囲外

- 想定: 従業員 10〜100 人。人事専任がいないか 1 人。情シスは不在か兼務。顧問社労士・税理士がいる場合もいない場合もある
- 雇用形態: 正社員・契約社員(有期)・パート/アルバイト。**業務委託(個人事業主との契約)は入退社ではない** — 契約書と支払い・アカウントの開始/終了として別に扱い、このスキルの「社会保険・雇用保険・住民税」の段取りは当てはめない
- 退職: 自己都合退職・契約期間満了・定年(および定年後の継続雇用)。**解雇・退職勧奨は範囲外** — 手続きの型を出す前に法的判断が要るので、その旨を伝えて専門家(社労士・弁護士)へつなぐ
- 扱わないこと: 保険料や税額の計算、加入可否・扶養可否の**判定**、届出の**提出代行**、就業規則や契約の**解釈**。これらは「揃えるべき情報」と「期限」を示したうえで担当者・専門家に渡す

## 登場人物

| 役割 | すること |
|---|---|
| 本人 | 書類の提出、口座・通勤経路・扶養の申告、貸与物の受領と返却、引継ぎ |
| 担当者(人事・総務) | 段取り全体の管理、労働条件の明示、法定書類の準備・回収、届出(または社労士への依頼)、台帳の記録 |
| 上長 | 配属・業務の割当、初日の受け入れ、退職時の引継ぎ確認 |
| 情シス(いなければ担当者が兼務) | アカウント発行と権限、PC 等の貸与、退職時の停止・回収・データ移管 |
| 顧問社労士・税理士(いれば) | 届出の作成・提出、判断が要る問い合わせの窓口 |
| 給与を扱う担当者 | 口座登録、住民税の特別徴収の切替、退職時の最終支払い |

## 使い方(応答の組み立て方)

1. **足りない前提を先に3つまで確認する**(それ以上は既定で進め「あとから変えられる」と添える): 雇用形態と入社/退職日 / 前職の有無(入社)・扶養家族の有無 / PC やアカウントの貸与・発行が要るか。パートなら週の所定労働時間と月額の見込み(社会保険・雇用保険の対象になるかを担当者が判断する材料になる)
2. **チェックリストは段階 × 担当 × 期限で出す。** 入社は「入社前 / 初日 / 入社後(〜1か月)」、退職は「申出〜最終出社の前 / 最終出社日 / 退職後」の三段。各行は `[ ] 項目 — 担当 — 期限 — 備考(揃える情報)`。期限は「◯日以内」の根拠を `references/deadlines.md` から引き、**日付に換算して**書く(「5日以内」より「◯月◯日まで」のほうが実務で使える)
3. **線引きは「できません」で終えない。** 判断が要る問いには、判断そのものは担当者・専門家に委ね、**その判断に必要な情報をこちらで揃える**言い方をする(→ よくある質問と線引き)
4. 台帳・管理表を作る文脈なら「記録項目の推奨」を出す。項目ごとに「何のために残すか」を添える(あとで探す・数える・引き継ぐ)

## 段取り

### 入社 — 入社前(内定〜前日)

1. **労働条件の明示** — 担当者 — 契約締結時(初日より前)。書面(または本人が希望すれば電子)で交付する。2024年4月から、**就業場所・業務の「変更の範囲」**の明示が全員に必要になり、有期契約には**更新上限の有無と内容**、無期転換申込権が発生する更新時には**申込機会と転換後の条件**の明示が加わった(→ `references/labor-conditions.md`)。雛形は厚生労働省のモデル様式を使い、契約書と通知書のどちらで明示するかを会社で決めておく
2. **本人から回収する書類の依頼** — 担当者→本人 — 初日まで。典型: 給与所得者の扶養控除等(異動)申告書 / 前職の源泉徴収票(同年に前職があるとき) / 雇用保険被保険者番号(前職があるとき。被保険者証など) / 基礎年金番号またはマイナンバー / 給与振込口座 / 通勤経路と費用 / 緊急連絡先 / 扶養家族の情報(いれば) / 健康診断の結果(3か月以内に受診済みなら雇入時健診の代わりになる項目がある)。**マイナンバーは利用目的(社会保険・税の届出)を示して取得し、本人確認の方法を決めておく**
3. **配属先・席・貸与物の準備** — 上長・情シス — 初日まで。PC・スマホ・鍵・社員証・入館証。貸与物は**貸与台帳に記録してから渡す**(退職時に回収漏れを起こさないため)
4. **アカウントの発行(前日または当日朝)** — 情シス — 初日。メール・チャット・グループウェア・業務システム。権限は**部署の標準セットから最小で**始めて必要に応じて足す(最初から広く出すと退職時に何を止めるべきか分からなくなる)。多要素認証は初日にセットさせる
5. **雇入時の健康診断の手配** — 担当者 — 入社時期に。常時使用する労働者を雇い入れるときは医師による健康診断が要る(前記のとおり3か月以内の受診結果で代えられる項目がある)。実施日と結果の保管場所を決めておく

### 入社 — 初日

1. 労働条件通知書・雇用契約書の締結確認、就業規則の周知、秘密保持誓約書などの社内書類 — 担当者・上長
2. 回収書類の受領とチェック(足りないものは期限つきで再依頼) — 担当者
3. 貸与物の受け渡しと受領サイン(台帳に日付と本人確認を残す) — 情シス
4. アカウント初期設定・多要素認証・セキュリティのルール説明 — 情シス
5. 受け入れ: 上長との顔合わせ、初週の予定、相談窓口を伝える — 上長

### 入社 — 入社後(〜1か月)

1. **健康保険・厚生年金保険の資格取得届** — 担当者(または社労士) — **資格取得日(入社日)から5日以内**。必要情報: 氏名・生年月日・住所・マイナンバーまたは基礎年金番号・報酬月額など。扶養家族がいれば被扶養者(異動)届を同時に(→ `references/deadlines.md`)。**パートは加入要件(週の所定労働時間・月額・雇用見込み・学生か・会社の規模)で対象かどうかが変わり、要件は 2027年10月から段階的に会社規模の下限が下がる**。該当するかの判断は担当者・社労士が行い、こちらは労働条件の数字を揃える(→ `references/social-insurance-scope.md`)
2. **雇用保険被保険者資格取得届** — 担当者(または社労士) — **雇入れ日の属する月の翌月10日まで**。対象の目安は週20時間以上かつ31日以上の雇用見込み。必要情報: マイナンバー・前職の被保険者番号(または職歴)
3. **住民税の特別徴収への切替** — 給与を扱う担当者 — 前職で特別徴収だった人は前職からの異動届の流れを確認、普通徴収だった人は本人の希望と市区町村の手続きを確認する。**判断はせず、状況(前職の有無・現在の徴収方法)を揃えて担当者に渡す**
4. 労働者名簿の作成(法定帳簿。→ 記録項目の推奨) — 担当者 — 雇入れ時
5. 1か月の振り返り: 権限の過不足、貸与物、書類の未回収 — 上長・担当者

### 退職 — 申出〜最終出社の前

1. **退職日と最終出社日の確定、退職届の受領** — 担当者・上長。有期契約の満了・定年は日付が先に決まっているので、**1〜2か月前から**この段取りを始める(定年後の継続雇用を希望する場合は、条件の提示と契約の締結を退職日前に。60歳以上で退職の翌日に再雇用する場合、社会保険の届出に就業規則・退職辞令・雇用契約書の写しが要る扱いがある — 詳細は担当者・社労士へ)
2. **引継ぎ計画** — 上長。引継ぎ書の項目(担当業務・取引先・進行中の案件・データの場所)を先に決め、最終出社日から逆算する
3. **返却物・停止対象の一覧づくり** — 情シス・担当者。貸与台帳と、本人が使っているアカウント一覧(共有パスワードや管理者権限があれば別扱いで洗い出す)。**最終出社日にすることを事前に一覧化**しておくと当日の漏れが消える
4. **本人へ渡す・受け取る書類の確認** — 担当者。離職票を希望するか(59歳以上は本人の希望に関わらず交付)、退職証明書が要るか(請求があれば遅滞なく交付、記載は請求された事項のみ)、退職後の健康保険の選択(任意継続は退職日の翌日から20日以内に本人が手続き / 国民健康保険 / 家族の扶養)は本人が決めるので、**選択肢と期限だけを伝える**
5. 残っている年次有給休暇の扱いを本人と確認(判断は就業規則と担当者) — 担当者
6. 住民税: 退職月によって残額の徴収方法が変わる(**1〜5月退職は原則、最終給与などから一括徴収**、6〜12月は本人の選択で一括か普通徴収か転職先で継続)。**方法の確定は給与を扱う担当者・税理士へ**、こちらは退職日と転職先の有無を揃える

### 退職 — 最終出社日

1. 貸与物の回収と台帳への記録(PC・スマホ・鍵・社員証・入館証・名刺・書類) — 情シス・担当者
2. **アカウントの停止**(退職日または最終出社日のどちらで止めるかを事前に決めておく)、メール転送・共有データの移管、共有パスワードの変更、管理者権限の付け替え — 情シス
3. 健康保険の資格確認書・保険証を持っていれば回収(マイナ保険証に移行した人からは回収するものが無い場合がある) — 担当者
4. 秘密保持・競業避止などの再確認と書面(会社の運用による) — 担当者
5. 引継ぎ完了の確認 — 上長

### 退職 — 退職後

1. **健康保険・厚生年金保険の資格喪失届** — 担当者(または社労士) — **退職日の翌日から5日以内**
2. **雇用保険被保険者資格喪失届(+離職票を希望する場合は離職証明書)** — 担当者(または社労士) — **退職日の翌々日から10日以内**。離職証明書には労働者名簿・出勤簿・賃金台帳などの写しが要る(→ `references/deadlines.md`)
3. **住民税の異動届出書** — 給与を扱う担当者 — 退職日の翌月10日まで
4. **源泉徴収票の交付** — 給与を扱う担当者 — 退職後1か月以内
5. 最終給与・退職金の支払い、社宅・貸与制度の精算 — 給与を扱う担当者
6. 労働者名簿に退職日と事由を記録、書類の保存(保存期間は法定 — 記録項目の推奨) — 担当者

## 記録項目の推奨

台帳(入退社台帳・貸与台帳・アカウント台帳)を作るなら、次を項目に持つ。**理由が言えない項目は入れない**(項目が多い台帳は更新されなくなる)。

| 台帳 | 項目 | 何のために残すか |
|---|---|---|
| 入退社台帳(1人1行) | 氏名 / 雇用形態 / 部署・上長 / 入社日 / 退職日と事由 / 手続きの状態(労働条件明示・社保・雇保・住民税・健診 それぞれ 済/未/対象外・日付) / 担当者 / 備考 | 期限管理と「誰がどこまでやったか」の可視化。退職事由は労働者名簿の法定項目でもある |
| 労働者名簿(法定) | 氏名 / 生年月日 / 履歴 / 性別 / 住所 / 従事する業務の種類 / 雇入れ年月日 / 退職年月日と事由(解雇の場合はその理由) / 死亡年月日と原因 | 労働基準法で作成・保存が義務(保存期間は法定 — 5年、当分の間3年)。上の入退社台帳と別に持つか、同じ台帳に法定項目を含めるかは会社で決める |
| 貸与台帳(1物品1行) | 物品 / 識別番号 / 貸与先 / 貸与日 / 返却日 / 状態 / 受領・返却の確認者 | 退職時の回収漏れ防止。棚卸しの材料 |
| アカウント台帳(1人×1サービス) | サービス名 / アカウントID / 権限レベル / 発行日 / 停止日 / 発行・停止の実施者 / 管理者権限や共有パスワードの有無 | 退職時に「何を止めるか」を迷わない。権限の棚卸し |
| 書類回収チェック(1人1行) | 扶養控除等申告書 / 前職の源泉徴収票 / 雇用保険番号 / 基礎年金番号・マイナンバー / 口座 / 通勤 / 緊急連絡先 / 健診結果 それぞれ 受領日 | 未回収の追跡。マイナンバーは**取得日・利用目的・廃棄日**を別に記録し、台帳本体には番号を書かない |

## 期限の考え方

期限は「起算日 + 日数」で書き、応答では日付に換算する。根拠と閲覧日は `references/deadlines.md` に置く(法改正で変わるため、**参照先の閲覧日が古ければ一次情報を見直す**よう促す)。

- 健康保険・厚生年金 資格取得届: 入社日から **5日以内** / 資格喪失届: 退職日の翌日から **5日以内**
- 雇用保険 資格取得届: 雇入れ月の **翌月10日** / 資格喪失届: 退職日の翌々日から **10日以内**
- 労働条件の明示: **契約締結時**(初日より前)
- 住民税 異動届: 退職日の **翌月10日** / 源泉徴収票: 退職後 **1か月以内**
- 任意継続(本人): 退職日の翌日から **20日以内**
- 社会保険の加入要件(パート): 会社規模の下限が **2027年10月・2029年10月・2032年10月・2035年10月**に段階的に下がる。加入対象が増えるタイミングを担当者に知らせる

## よくある質問と線引き

- 「この人は社会保険に入れないといけませんか?」→ 判定は担当者・社労士。こちらは**週の所定労働時間・月額の見込み・雇用期間・学生かどうか・会社の被保険者数**を揃えて渡す。「要件はこの5つで、御社は◯人規模なので 2027年10月から対象が広がります」まで言う
- 「扶養の範囲内で働きたいと言われました」→ 扶養の可否は本人の家族の保険者と税の話で、会社が判定するものではない。**労働条件(時間・月額)を明示し、社会保険の加入要件に触れるかどうかを担当者が確認する**段取りにする
- 「住民税は一括徴収ですか?」→ 退職月と本人の希望・転職先の有無で変わる。**退職日・転職先の有無・本人の希望**を揃えて給与担当・税理士へ
- 「解雇したい社員がいます」→ このスキルの範囲外。手続きの前に法的判断が要るので、社労士・弁護士への相談を勧め、こちらは**経緯の記録・貸与物とアカウントの一覧**を整えて待つ
- 「業務委託の人が来月から来ます」→ 入退社ではない。契約書・支払い条件・アカウントの発行と終了日を段取りする(社会保険等の項目は当てはめない)
- 「英語で対応してほしい」→ 段取りは同じ。書類名は日本語の正式名称を残し、英語の説明を添える
