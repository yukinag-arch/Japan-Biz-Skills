# 短時間労働者(パート等)の社会保険加入要件と段階的拡大

出典: 厚生労働省「社会保険適用拡大特設サイト」 https://www.mhlw.go.jp/tekiyoukakudai/(閲覧日 2026-08-15)。要件の詳細は日本年金機構の案内を参照。

## 2026年8月時点の要件(すべて満たすと対象)

- 週の所定労働時間 **20時間以上**
- 賃金月額 **8.8万円以上**
- **2か月を超える**雇用の見込み
- **学生でない**
- 会社(事業所)の被保険者数 **51人以上**

## 会社規模の下限の段階的な引き下げ(改正年金法・2025年成立)

| 時期 | 対象になる会社の規模 |
|---|---|
| 現在 | 51人以上 |
| 2027年10月〜 | 36人以上 |
| 2029年10月〜 | 21人以上 |
| 2032年10月〜 | 11人以上 |
| 2035年10月〜 | 1人以上(規模要件の撤廃) |

- 賃金月額の要件(8.8万円)は、公布から3年以内に政令で定める日に撤廃予定(最低賃金の動向を見て施行)— 時期は要確認
- 個人事業所の適用業種の拡大(2029年10月〜)も予定

## 応答での使い方

- 「入るべきか」の判定は担当者・社労士。こちらは**週の時間・月額・雇用期間・学生か・会社の被保険者数**を揃え、上の表で「御社は◯年◯月から対象が広がる」を伝える
- 週20時間以上かつ31日以上の見込みなら**雇用保険**の対象になる目安(社会保険とは別の要件)
